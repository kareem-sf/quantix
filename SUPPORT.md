# Support

Quantix is under active pre-release development and is not yet a publicly qualified production release.

Use GitHub Issues for reproducible defects and well-scoped product/change requests. Search existing issues first and include the affected commit/version, operating system, observable behavior, reproduction steps, and non-sensitive diagnostics.

Do not upload real confidential Tender Packages, credentials, tokens, client data, or other sensitive material to a public issue.

Security vulnerabilities must follow `SECURITY.md` rather than the normal issue flow.
