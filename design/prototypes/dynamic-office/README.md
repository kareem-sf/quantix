# Quantix office concept

A clickable design prototype of the agreed adaptive office. It uses synthetic staff, messages, drawings and decisions and never calls Quantix's backend or any model provider. The application has not been changed by this prototype.

## Open locally

From this directory:

```powershell
npm install --ignore-scripts
npm run assets
npm start
```

The server prints its loopback URL. It serves only this prototype directory. Inter fonts are copied from the existing project dependency; the checked-in generated assets let the HTML also be inspected without rebuilding portraits.

## Explore

1. Start at **Manager alone**. Customize the Manager or review the example plan.
2. Open the live office and use **Play example** or **Next event** to see the example team form.
3. Open a staff desk, follow a source link, then return to the prior view.
4. Switch between **Highlights** and **All exchanges**.
5. Use **Ready to review**, inspect evidence and save a clearly labelled demo decision.
6. Toggle light/dark and reduced motion.

The preview's state controls and canned example messages are demonstration fixtures. They are not a staff roster or workflow implementation for production. Native tray behavior, real model execution, staff generation, durable private contexts and actual Tender decisions belong to the implementation plan.

Portrait illustrations use local DiceBear Notionists rendering; attribution and licenses are in assets/. No image HTTP service or API key is used.
