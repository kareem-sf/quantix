# Quantix dynamic office concept

Interactive, synthetic design prototype. It is separate from the Quantix application, uses no customer data, makes no model calls and creates no real staff or Tender decisions. Sample names and work are demonstration fixtures only.

The accepted direction is a balanced Manager/document workspace, expandable live office, illustrated AI portraits, important exchanges by default and complete retained example conversations on demand. Only the Manager is present in the opening state. The other staff appear through a clearly labelled example sequence. The engineer can preview Manager customization, inspect a staff desk, open source evidence and review a synthetic decision.

Three primary states: Manager alone; team at work; result for review. Preserve current brand cues—Inter, quiet teal, readable white/dark work surfaces—and extend them into a focused engineering workspace. Motion explains creation, handoff and completion. Native dialog controls support keyboard focus; reduced motion remains usable.

Planned verification: desktop light/dark, reduced motion, narrower/scaled layout, state switching, office expansion, sample event playback, profile/evidence navigation, Manager editing and synthetic decision handling. Browser results apply to this prototype only.

Assets: locally rendered DiceBear Notionists illustrations; style published under CC0. DiceBear code/style packages are pinned in this prototype package. Inter font files are copied from the existing project dependency and retain its license. No avatar HTTP service is used.

Direction contract for review:

- THESIS: Keep the engineer's conversation and working evidence together, with a team that becomes visible as the example task requires it.
- OWN-WORLD: Extend Quantix's existing Inter, quiet teal, navy navigation and light/dark work surfaces. This is code-led inside the incumbent identity; no new brand world or approved image comp is involved.
- STORY: Start with only the Manager; inspect an example plan; play/step through illustrated staff creation and exact artifact handoffs; open a profile/source; review a synthetic decision.
- FIRST VIEWPORT: The opening state presents the Manager, one example package and a clear action. The working/review states present conversation and source-linked draft side by side. The expandable office shows the actual local example sequence, labelled illustrative.
- FORM: A desktop application shell, balanced work panes, expandable office with staff cards and transcript, focused profile/source/review dialogs. Narrow layouts reflow. No staff, messages or approvals are connected to the production application.
