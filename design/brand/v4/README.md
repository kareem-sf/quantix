# Quantix Transparent Brand Package v4

All assets in this package are transparent.

## Important
- No dark background boards
- No light background boards
- No black or white tiles
- No boxes, borders, or containers behind the logo

## Included
- Transparent SVG master logos
- Transparent flat and monochrome SVG variants
- Transparent icon SVGs and PNGs
- Transparent web favicon package
- Transparent desktop icons
- Large-format transparent exports
- Minimal HTML preview
