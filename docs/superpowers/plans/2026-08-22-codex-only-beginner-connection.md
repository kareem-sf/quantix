# Codex-Only Beginner Connection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce Quantix to one ChatGPT connection and make browser sign-in automatic for non-technical construction engineers, with device authorization available only as a troubleshooting fallback.

**Architecture:** The Rust Host keeps the existing direct ChatGPT PKCE and HTTPS/SSE adapter, deletes the Anthropic/Gemini branches, and adds a bounded device-auth fallback beside the browser flow. The renderer presents one ChatGPT card, prepares recommended model defaults after connection, and hides technical model provenance behind an advanced disclosure.

**Tech Stack:** Rust 1.97.1, Tauri 2, reqwest blocking client, React 19, TypeScript 7, ts-rs generated declarations.

**Spec:** `docs/superpowers/specs/2026-08-22-codex-only-beginner-connection-design.md`

## Global Constraints

- Quantix supports exactly one AI provider kind: serialized value `codex`, displayed to users as `ChatGPT`.
- Delete Anthropic and Gemini paths; do not add migrations, aliases, compatibility deserializers, or fallbacks.
- Browser PKCE is primary and uses ports `1455` then `1457`, `codex_cli_simplified_flow=true`, and `originator=quantix`.
- Device authorization is an explicit fallback using OpenAI's device endpoints and a 15-minute local timeout; it is never selected silently.
- The UI never exposes OAuth terminology, port numbers, PIDs, API keys, tokens, raw provider errors, or provider routing.
- Tokens remain exclusively in `<Quantix Application Home>/auth.json`; disconnect deletes the file.
- Installation schema version is exactly `25`; Tender schema version is exactly `36`.
- Generated declarations under `src/bindings` are generated by `src-tauri/src/bin/export_bindings.rs` and are never hand-edited.
- The user explicitly prohibited tests. Do not run `npm test`, `npm run verify`, `npm run check`, Vitest, Cargo test, Clippy, development-server, or production-build commands. Update affected test sources but do not execute them.
- A non-test binding export command may compile the Rust target solely to regenerate declarations; report it as compilation/binding evidence, not test evidence.
